# Feature Mart — витрина признаков для ML
Построение витрины признаков из событийной истории без data leakage: временные окна, агрегаты по действиям клиентов и расчёт поведенческих признаков.  
Подготовка данных для задач скоринга и предсказания оплаты.

## Описание

Проект посвящён построению дневной витрины признаков на основе событийной истории клиентов.

Цель — подготовить признаки для последующего обучения модели, используя только данные, доступные на момент `snapshot_date`.

---

## Данные

* `actions_log` — история действий клиента: звонки, SMS, обещания, платежи
* `daily_snapshot` — дневной срез состояния клиента

---

## Ключевое требование

При построении признаков нельзя использовать события на дату среза и позже:
`action_dttm < snapshot_date`  
*Чтобы предотвратить утечку данных из будущего и сделать признаки корректными для обучения моделей.*

---

## Логика построения

Для каждой строки из daily_snapshot строятся признаки по истории событий конкретного клиента:

* последние 7 дней — контакты: звонки, SMS
* последние 30 дней — обещания и платежи
* вся история — дата последнего платежа

---

## Признаки

* `calls_last_7d` — число звонков за 7 дней
* `sms_last_7d` — число SMS за 7 дней
* `promises_last_30d` — число обещаний за 30 дней
* `payments_amount_last_30d` — сумма платежей за 30 дней
* `promised_amount_last_30d` — сумма обещанных платежей за 30 дней
* `days_since_last_payment` — количество дней с последнего платежа

---

## Обработка данных

* отсутствие событий → 0 для count/sum-признаков
* отсутствие платежей → `NaN` для `days_since_last_payment`

---

## Дополнительный анализ

Дополнительно сформирована выборка топ-20 клиентов:

* с максимальным числом контактов за 7 дней
* без оплат за 30 дней

Это позволяет находить проблемные сегменты клиентов с высокой активностью, но без финансового результата.

## Результат

Сформирована дневная витрина признаков `feature_mart`, пригодная для дальнейшего использования в ML-пайплайне:

* обучения моделей (скоринг, вероятность оплаты)
* анализа поведения клиентов
* дальнейшего feature engineering
